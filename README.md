WQTerm là terminal mã nguồn mở dành cho iOS 27 (không jailbreak), khai thác lỗ hổng worse_query để truy cập container của mọi ứng dụng khác trên thiết bị. Tích hợp sẵn AI CLI (Gemini, Claude, Codex) chạy offline, hệ thống backup write-ahead bảo vệ dữ liệu, và trình preview đa định dạng (plist, SQLite, hex, ảnh, PDF...). Build tự động qua GitHub Actions, phát hành dưới dạng IPA không ký để sideload qua SideStore/AltStore. Hỗ trợ iOS 26.0–27.3 Beta 1.
